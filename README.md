# Interactive Map Mod

This mod connects the game with the interactive map, creating ease of access between the two.



### Installing

(Prerequisites, the mod loader and api)

Download the 'InteractiveMapMod.zip' from the latest release.

Extract it, placing in the 'mods' folder of your mio directory. (It should go "MIO/mods/InteractiveMapMod/InteractiveMapMod.dll")

Once installed, open the game.

Wait about two minutes for the map itself to install. (to check if it worked, there should be a new folder in the map mod directory)

Once installed, you can toggle it in-game by pressing CTRL+M. This doesn't work on the main menu.
